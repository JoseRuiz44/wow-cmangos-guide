# CMaNGOS WoW Classic 1.12.1 - Guía Interactiva

## Qué incluye
- Comandos GM por **secciones y subsecciones**
- Tarjetas con botón **Copiar**
- Ítems por:
  - **Conjuntos/Sets**
  - **Legendarios**
  - **Épicos**
  - **Raros**
- Tooltip al pasar el ratón para comparar rápido

## Uso
Abre `index.html` en el navegador.

## Estructura
- `data/commands.json` → comandos
- `data/items.json` → ítems

Puedes ampliar ambos JSON sin tocar la UI.
