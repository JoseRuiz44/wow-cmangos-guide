# CMaNGOS WoW Classic 1.12.1 - Guía Interactiva

Web estática para consultar comandos de GM y generar rápidamente comandos de ítems para servidores basados en CMaNGOS/mangos (enfoque 1.12.1).

## Cómo usar

1. Abre `index.html` en cualquier navegador.
2. Usa el buscador y filtro por categoría para encontrar comandos.
3. Pulsa **Copiar** para llevarte el comando al portapapeles.
4. En **Ítems**, ajusta cantidad y copia el `.additem` al instante.

## Nota importante

- Los comandos pueden variar según la revisión de CMaNGOS o el core derivado.
- Esta guía sirve como base práctica y rápida en juego.
